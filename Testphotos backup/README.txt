RAW test files for an "extract embedded JPEG + read EXIF" script
================================================================
manifest.csv = answer key, generated by ExifTool 13.59 (the reference reader).

full_raws/              Real, complete camera RAW files with embedded JPEG previews.
  M0054341_01_00005.cr2           Canon Rebel XTi. Orientation = Rotate 180 (preview is NOT pre-rotated).
  RAW_CANON_40D_SRAW_V103.CR2     Canon 40D, sRAW (small RAW) variant.
  RAW_CANON_5DMARK2_PREPROD.CR2   Canon 5D Mark II, full-size 5616x3744 preview.
  iss030e122639.NEF               Nikon D3S, ISS photo. Has 2 JPEGs: small PreviewImage + full JpgFromRaw.
  iss042e297200.NEF               Nikon D4, ISS photo. 3 JPEGs (PreviewImage, JpgFromRaw, OtherImage).
  RAW_KODAK_DC50_é.KDC            1990s Kodak. NO JPEG preview (bitmap thumb only). Accented filename.
  RAW_SIGMA_SD9_SRGB.X3F          Sigma Foveon. NO JPEG preview (bitmap thumb only).

stripped_metadata_only/ ExifTool's test files: real headers/EXIF, image data removed (KB-sized).
  Good for EXIF parsing across many formats (CR3, CRW, DNG, RAF, RW2, MRW, IIQ, X3F...).
  Most have no usable preview: tests your "no JPEG found" path.
  FujiFilm.raf, Panasonic.rw2, SigmaDP2.x3f do have tiny JPEGs.

broken/                 Should be handled gracefully, never crash.
  truncated_halfway.NEF   first 2 MB of a real NEF (header + EXIF intact, image data cut)
  truncated_early.CR2     first 300 KB of a real CR2 (preview cut off mid-JPEG)
  empty_zero_bytes.nef    0 bytes
  actually_a_jpeg.cr2     a JPEG with a RAW extension
  actually_a_tiff.dng     a plain TIFF with a .dng extension
  text_file.arw           text
